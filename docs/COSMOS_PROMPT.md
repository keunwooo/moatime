# 세 번째 테마 "은하" — 구현 요청 프롬프트

> 아래 구분선 밑을 그대로 붙여 넣어 구현을 요청한다.
> 지금 저장소의 구조(`README.md`, `docs/LIVING_WORLD.md`, `docs/DESIGN.md`)를 전제로 썼다.

모아 타이머에 세 번째 테마 **은하**를 추가해줘. 장면 이름은 **"처음의 우주"**다.

## 0. 핵심 경험

**"집중한 시간만큼 우주가 자란다."**

빛 한 점에서 우주의 역사가 시작된다. 빅뱅 → 첫 빛 → 첫 별 → 별의 죽음과 성운 → 행성 → 생명의 행성 → 은하로 이어지는 흐름을, 사용자가 집중한 시간 위에 압축해서 보여준다.

- 처음 25분이면 빅뱅에서 첫 행성계까지 간다. 소개 문구와 공유 이미지는 이 경험을 중심으로 만든다.
- 그 뒤에는 별이 태어나고 죽으며 성단과 은하가 자란다. 행성 하나에는 바다와 생명이 생긴다.
- 세션이 끝날 때마다, 그동안 켜진 별들을 이은 별자리가 하나씩 남는다.

기존 "우주" 테마(외계 행성 개척지)와 겹치지 않도록 이 테마에는 사람, 기계, 전투가 나오지 않는다. 일하는 주체는 중력과 빛이다.

## 1. 기존 구조와의 관계

**따를 것**
- 누적 실행 시간 W와 결정적 시뮬레이션: 결과는 W와 시드의 순수 함수이고, 세션을 어떻게 나눠도 같다(5분×3 = 15분×1).
- 진행 단계 1~10. 단계는 내려가지 않는다.
- `src/world/` 시간 계층, 30분 블록 타임라인, 세션 맞춤 사건(`pace.ts` 방식).
- Event Director의 채널과 동시 상한, 카드 디오라마와 카메라 리그.
- 과슈 붓 질감(`scene/paint`). 매 프레임 다시 그리는 Graphics는 `scene/gfx.ts` 규칙을 따른다.
- 사건은 실행 중에 그 시점을 직접 지날 때만 재생한다. 새로고침, 탭 복귀, 시간 점프 뒤에는 연출 없이 현재 상태로 바로 맞춘다.

**바꾸지 않을 것**
- 타이머, 저장, 탭 동기화 코드
- 숲·우주의 시뮬레이션과 장면, 기존 저장 데이터와 진행
- 기존 테스트는 모두 그대로 통과해야 한다. 은하 장면은 지연 로드 chunk로 분리한다.

## 2. 우주의 나이 A

- **A = W − W₀**로 정의한다. W₀는 이 세계에서 은하 테마를 처음 고른 순간의 W이며, 한 번 저장하면 바꾸지 않는다.
  - 이유: 이미 수십 시간을 쌓은 사용자도 이 테마를 처음 열면 빅뱅부터 보게 하기 위해서다.
  - 다른 테마로 집중한 시간도 W이므로 A에 더해진다. 숲·우주가 같은 W를 공유하는 규칙과 같다.
  - "새 풍경"으로 세계를 새로 만들면 W₀도 새로 정해진다.
- 설정 메뉴에 **"새 우주 시작"**을 둔다. 확인 대화상자를 거쳐 이 테마만 A=0으로 돌린다. 숲·우주와 누적 시간은 바뀌지 않는다.
- 은하의 시뮬레이션과 장면은 A만 읽는다.

**시간 척도(A 기준)**

| 구간 | 길이 | 성격 |
|---|---|---|
| 연대기 | 0 ~ 24분 20초 | 정해진 순서대로 진행한다. 1~3분마다 큰 변화가 있다 |
| 항성계 하나 | 평균 12분(9~16분) | 첫 행성계 뒤로 반복되는 단위(숲의 나무 한 그루에 해당) |
| 성단 | 항성계 4개, 약 1시간 | 숲의 군락에 해당 |
| 구역 | 성단 4개, 약 4시간 | 숲의 구역에 해당 |

## 3. 화면 구도

시점은 고정한다. 왼쪽 위의 원경에서 왼쪽 성운을 거쳐 하단 중앙의 집의 별로 흘러내리고, 오른쪽 궤도와 은하로 빠지는 S자 흐름을 만든다. 타이머는 그 사이의 고요한 여백에 둔다.

```
데스크톱(가로)
┌────────────────────────────────────────────────────────────┐
│ 상단 바                                                     │
│   우주 거미줄(원경, 좌상단이 가장 뚜렷)     은하 원반(원경, 우상단) │
│   ─ ─ ─ ─ 사건 띠(상단 바와 타이머 사이) ─ ─ ─ ─               │
│ 성운 A          ┌──────────────────┐        두 번째 성운·성단  │
│ (좌측 가장자리)   │      타이머       │        (우측 가장자리)     │
│   ╲             └──────────────────┘                         │
│    ╲__ 성운 꼬리가 하단 중앙으로 흘러내림                          │
│ ─ ─ 근경: 집의 별(하단 중앙)과 비스듬한 궤도면이 하단 띠를 가로지름 ─ ─ │
│   생명의 행성(궤도 앞쪽에서 가장 큼)   소행성대     가스 행성         │
└────────────────────────────────────────────────────────────┘
  광고 영역(장면 아래의 별도 영역, 기존과 같음)
```

| 요소 | 데스크톱 | 모바일(세로) |
|---|---|---|
| 타이머 여백 | x 0.33–0.67, y 0.26–0.62 | 상단 중앙 y 0.12–0.48 |
| 성운 A | x 0–0.32, y 0.25–0.95. 꼬리가 하단 중앙으로 흐름 | 좌측 y 0.48–0.92 |
| 집의 별 | x≈0.50, y≈0.86 | x 0.5, y 0.88 |
| 궤도면 | y 0.70–0.97, x 0.06–0.94, 기울기 15~20°. 궤도의 뒤쪽도 y 0.70 아래 | y 0.74–0.98 |
| 은하 | x 0.64–1.0, y 0.06–0.42 | 타이머 아래 우측, x 0.55–1.0, y 0.50–0.64 |
| 성단 슬롯 | 좌측 성운 안 앞·뒤, 우측 x 0.70–0.97, y 0.30–0.68 앞·뒤(숲의 군락 c0~c3 순서) | 하단 양옆 |
| 사건 띠 | y 0.08–0.24, 그리고 타이머 양옆 3분의 1 구역 | 타이머 양옆과 하단 |

- 타이머 여백에는 큰 천체와 사건을 두지 않는다. 그 뒤의 배경 별은 어둡고 움직이지 않는다.
- **구역이 바뀌어도 화면을 옆으로 옮기지 않는다.** 새 구역의 성단은 같은 슬롯의 앞쪽에 생기고, 이전 구역은 한 겹 뒤로 물러나 작고 흐려진다. 자세히 그리는 구역은 최대 3개이고, 그보다 오래된 구역은 원경 LOD와 은하수 띠로 합친다.
- 집의 항성계와 생명의 행성은 언제나 근경에 남는다.

## 4. 미술 방향

**스타일: 수채 번짐과 과슈**
- 성운: 젖은 종이에 떨군 수채 물감처럼 번진다(wet-on-wet). 가장자리에 번짐 띠가 생기고, 겹칠수록 색이 진해진다. 어두운 먼지 띠는 마른 붓으로 그린다.
- 별: 과슈 점에 부드러운 후광을 두른다. 회절 십자와 렌즈 플레어는 넣지 않는다.
- 행성: 둥근 과슈 원반이다. 밝은 면은 **자기 별 쪽**을 향하고, 명암 경계는 부드럽게, 대기는 얇은 빛 테로 표현한다.
- 종이 질감 오버레이는 숲·우주와 같은 계열을 쓴다.
- 쓰지 않을 것: 사진 같은 실사, NASA·JWST 사진 속 성운 모양을 그대로 옮긴 그림(특정 기둥 모양 등), SF 영화의 함선이나 로고, 네온 발광의 남용.

**팔레트**

| 이름 | hex | 쓰임 |
|---|---|---|
| 심연 | `#120F2A` | 바탕(남보라 기운이 있는 어둠) |
| 밤 안개 | `#2A2550` | 원경 거미줄, 먼지 |
| 불씨 | `#F3B07C` | 빅뱅, 뜨거운 안개, 노란 별 |
| 성운 장미 | `#D47FA6` | 수소 성운 |
| 물빛 청록 | `#6CC9C1` | 산소 성운, 이온화 거품 |
| 별먼지 금 | `#E8C27A` | 별먼지, 별자리 선 |
| 첫 별 | `#CFE0FF` | 1세대 별 |
| 생명 바다 / 생명 초록 | `#3F7FA6` / `#84B47C` | 생명의 행성 |
| 문자 | `#EEF0FA` | UI |

- 순백(`#FFFFFF`)은 쓰지 않는다. 화면에서 가장 밝은 것은 별의 중심 몇 픽셀이다.
- UI는 우주 테마처럼 밝은 글씨에 어두운 베일을 쓴다. 토큰은 `[data-theme="cosmos"]`에 두고, 탭 아이콘은 나선 모양으로 한다.

**보는 맛을 만드는 디테일**
- 별이 켜지면 가까운 성운 가장자리가 그 별의 색으로 물든다.
- 행성의 그림자가 원반과 고리 위에 떨어진다.
- 혜성 꼬리는 두 갈래다. 금빛 먼지 꼬리는 휘어지고, 청록 이온 꼬리는 곧게 뻗는다.
- 초신성 잔해는 수십 분에 걸쳐 천천히 퍼지며 다음 성운의 재료가 된다.
- 은하가 돌면 먼지 띠도 함께 돈다.
- 생명의 행성 바다에 비친 별빛(작은 반사광)이 자전을 따라 움직인다.

## 5. 연대기: 빅뱅에서 첫 행성계까지 (A 0 ~ 24분 20초)

|---|---|---|---|---|

| 8:00–9:30 | 첫 별의 마지막 | 첫 별이 부풀면서 청백 → 주황 → 붉은색으로 바뀐다 | 8~12초 주기의 느린 맥동 | 첫 별이 마지막 숨을 쉬어요. |
| 9:30–10:30 | 첫 초신성 | 별이 잠깐 오므라든 뒤 빛 껍질이 퍼진다. 금(별먼지), 청록, 장미빛의 겹고리 | 3초 이상에 걸쳐 밝아지고, 밝은 곳은 국소 영역뿐이다. 껍질은 감속하며 60초 넘게 퍼진다 | 첫 별이 생을 마치며 별먼지를 흩뿌렸어요. |
| 10:30–15:00 | 첫 성운 | 껍질이 흩어져 좌측 가장자리의 수채 성운이 되고, 꼬리가 하단 중앙으로 흘러내린다. 먼지 기둥과 어두운 먼지 띠가 생긴다 | 성운 결 2~3겹이 서로 다른 속도로 흐르고, 밝기가 느리게 호흡한다 | 별먼지가 모여 성운이 되고 있어요. |
| 15:00–18:30 | 별의 요람 | 성운 꼬리 끝의 매듭이 붉게 달아오른다(원시별). 가스가 2~3줄기 소용돌이로 흘러들고, 가는 양극 제트가 생긴다 | 흘러드는 가스 띠가 느리게 감긴다 | 성운 속에서 새 별이 자라요. |
| 18:30–20:00 | 집의 별 | 하단 중앙에서 따뜻한 노란 별이 켜진다. 별빛이 성운에 빈 방을 깎아 낸다 | 12초 점화 램프. 빈 방은 40초에 걸쳐 열린다 | 따뜻한 별이 켜졌어요. 이 별이 우리의 집이 돼요. |
| 20:00–22:30 | 원반 | 별 둘레로 비스듬한 먼지 원반이 하단 띠를 가로지르고, 원반 안에 띠가 갈라진다 | 원반 결이 돈다 | 별 둘레에 먼지 원반이 돌아요. |
| 22:30–24:20 | 첫 행성들 | 띠가 뭉쳐 행성 셋이 차례로 생긴다(각 30초): 안쪽의 작은 암석 행성, 가운데의 붉은 마그마 행성(미래의 생명의 행성), 바깥의 가스 행성. 남은 먼지는 소행성대가 된다 | 덩어리 → 둥근 구 → 색 순서로 생기고, 생기는 대로 공전을 시작한다 | 먼지가 뭉쳐 첫 행성들이 생겼어요. |

- 25분 세션의 0·25·50·75·100% 시점(0:00 / 6:15 / 12:30 / 18:45 / 25:00)은 각각 빛 한 점 / 첫 별들 / 성운 / 집의 별 점화 / 첫 행성계로, 한눈에 다르게 보여야 한다.
- 첫 행성계는 24분 20초에 끝난다. 그래서 첫 25분 세션의 완료 연출과 겹치지 않는다.
- 연대기 동안에는 세션 사건(12절)을 얹지 않는다. 연대기 자체가 1~3분마다 일어나는 사건이다.

## 6. 진행 단계 1~10

단계는 시간이 아니라 시뮬레이션의 사실에서 계산하고, 내려가지 않는다.

| 단계 | 이름 | 조건 | 대략 A |
|---|---|---|---|
| 1 | 첫 빛 | A=0 | 0 |
| 2 | 우주 거미줄 | 우주가 투명해지고 거미줄이 생김 | 2분 30초 |
| 3 | 첫 별 | 첫 별 점화 | 4분 30초 |
| 4 | 별먼지와 성운 | 첫 초신성 | 10분 |
| 5 | 첫 행성계 | 집의 별의 행성 셋 완성 | 24분 20초 |
| 6 | 성단 | 항성계 4개(집 포함) | 약 1시간 |
| 7 | 은하의 탄생 | 항성계 8개 + 은하 원반 | 약 2시간 |
| 8 | 생명의 행성 | 바다 60% 이상 + 생명 출현 | 약 3시간 |
| 9 | 이웃 은하 | 구역 1 완성(항성계 16개) + 은하 핵 각성 | 약 4시간 |
| 10 | 스스로를 바라보는 우주 | 구역 2 완성 + 생명의 행성의 첫 불빛 | 약 8시간 |

단계는 사건의 자격 조건, 화면 복잡도, 상태 문구, "자세히"에 쓴다.

## 7. 작업과 자원 (시뮬레이션)

**일하는 주체는 "중력의 흐름"이다.** 가스 저장소(거미줄 매듭, 성운)에서 형성 지점으로 빛 입자 띠가 소용돌이치며 흘러든다. 흐름 한 번이 시뮬레이션 단계 하나이며, 숲지기의 물 긷기나 드론의 운반·하역에 해당한다.

| 자원 | 생기는 곳 | 쓰임 | 모습 |
|---|---|---|---|
| 가스(수소) | 거미줄 매듭, 성운 | 별을 만든다 | 장미·보랏빛 입자 |
| 별먼지 | 별이 죽을 때만 생긴다(초신성, 늙은 별이 벗는 껍질) | 암석 행성, 위성, 소행성대 | 금빛 반짝임 |
| 얼음 | 원반 바깥쪽 | 혜성이 되어 생명의 행성에 바다를 만든다. 얼음 위성, 고리 | 흰 청록 |

**규칙**
- **먼지 없이는 행성도 없다.** 1세대 별은 행성 없이 크고 푸르게 짧게 산 뒤 초신성으로 별먼지를 남긴다. 그래서 시간이 갈수록 항성계가 풍성해진다(행성 1~2개에서 최대 6개, 위성과 고리 추가).
- 큰 푸른 별은 생긴 지 40~90분 뒤 초신성이 되어(시뮬레이션 사건) 별먼지와 새 성운 조각을 남긴다. 작은 별은 사라지지 않는다. **집의 별과 생명의 행성은 절대 사라지지 않는다.**
- 회계 불변식: 들어온 양 = 쓴 양 + 예약 + 남은 양. 음수는 없고, 사건은 정수 ms 순서로 처리한다.
- 숲처럼 한 번에 하나의 항성계만 형성된다. 흐름의 수는 단계에 따라 1에서 3까지 늘어난다.
- "자세히"에는 가스·별먼지·얼음의 양, 별·행성·성단의 수, 다음 이정표를 보여준다.

## 8. 항성계 하나가 생기는 과정 (반복 단위)

| 진행 | 변화 |
|---|---|
| 0–10% | 앞 항성계에서 다음 매듭으로 가스 흐름이 이어진다 |
| 10–25% | 매듭이 수축하며 붉게 달아오른다(원시별). 가는 양극 제트가 생긴다 |
| 25–35% | 점화. 10~12초 밝기 램프. 주변 성운이 빛을 받아 밝아지고 빈 방이 열린다 |
| 35–55% | 비스듬한 먼지 원반이 생기고, 원반 결이 돌며 띠가 갈라진다 |
| 55–85% | 행성이 하나씩 생긴다(각 8~12초). 덩어리 → 둥근 구 → 색 순서다. 안쪽은 암석, 바깥은 가스·얼음 |
| 85–95% | 남은 먼지가 소행성대와 혜성 구름이 되고, 행성들이 공전을 시작한다 |
| 95–100% | 다음 매듭 쪽으로 가스 흐름이 뻗는다. 이 그림은 다음 단위의 0%와 같다 |

- 변주는 해시로 정한다: 별의 색(붉은 왜성, 노란 별, 푸른 거성, 7단계부터 쌍성), 행성 수(별먼지 양에 비례), 고리, 위성.
- 중경에 있는 항성계라 평소에는 행성이 작은 점과 고리로 보인다. 색은 근접 프레이밍에서만 구분된다.

## 9. 생명의 행성

집의 별의 가운데 행성이다. 근경 궤도를 돌며, 궤도 앞쪽에서 가장 크게 보인다(1440×820 기준 지름 56px 이상, 뒤쪽에서도 38px 이상).

| A | 상태 | 보이는 것 |
|---|---|---|
| 24분 | 마그마 행성 | 어두운 표면에 붉은 균열 빛 |
| 약 45분 | **달의 탄생**(이정표) | 작은 원시행성이 비스듬히 스친다(섬광 없음). 파편 고리가 생기고, 90초 동안 고리가 뭉쳐 달이 된다 |
| 24~70분 | 식어 감 | 균열 빛이 줄고 회갈색 지각이 드러난다. 엷은 대기가 생긴다 |
| 1시간 10분 ~ 2시간 20분 | 바다 | 원반 바깥의 얼음 덩어리가 혜성이 되어 2~4분마다 하나씩 날아온다(시뮬레이션 단계). 낮은 곳부터 바다가 차오른다(0 → 70%) |
| 약 2시간 20분 | 대기와 구름 | 흰 구름 띠와 극관이 생긴다. 12분 자전이 구름과 대륙의 이동으로 보인다 |
| 약 3시간 | **생명**(이정표) | 얕은 바다의 해안에서 초록빛이 60초에 걸쳐 번지기 시작하고, 이후 몇 시간 동안 대륙으로 퍼진다 |
| 3시간 이후 | 계절 | 1년 72분(숲의 계절과 같은 길이). 반구의 색이 초록 ↔ 황토로 바뀌고, 극관 크기가 달라진다 |
| 약 8시간 | **첫 불빛**(이정표) | 밤면의 해안선을 따라 작은 따뜻한 불빛이 30초에 걸쳐 하나씩 켜진다. 궤도에 작은 반짝임 1~2개가 생긴다 |

| A | 보이는 것 |

- A가 아무리 커져도 카드 수와 텍스처 수는 상한에서 멈춘다.

## 12. 사건

사건은 네 종류다.

**① 이정표** — 시뮬레이션(W)에 묶인다. 한 번만 일어나며, 성장의 원인이나 결과다.
- 빅뱅, 첫 빛, 첫 별, 첫 초신성, 첫 성운, 집의 별, 첫 행성계
- 두 번째 성운(약 35분), 달의 탄생(약 45분), 첫 성단(약 1시간), 바다의 시작(약 1시간 10분), 가스 행성의 고리(약 1시간 30분), 은하 원반(약 2시간), 생명(약 3시간), 은하 핵 각성(약 4시간), 첫 불빛(약 8시간)
- 실행 중에 지날 때만 연출한다. 상태 문구로 한 줄 알리고, "자세히"의 **우주 연표**에 A와 날짜를 남긴다.

**② 세션 사건** — `pace.ts` 방식이다. 화면 연출 전용이며 성장에 영향을 주지 않는다.
- 첫 행성계(24분 20초) 이후부터 일어난다.
- 첫 사건은 세션 시작 1분 30초~3분 30초 사이, 그 뒤로는 4~6분 30초마다 온다. 사건 사이는 최소 3분 30초다. 세션이 끝나기 1분 전까지 끝난다.
- 5분 세션에도 하나가 온다. 2분 미만 세션에는 없다.
- 사건 하나의 길이는 40~120초다. 이정표나 드문 사건과 겹치면 미룬다.
- 같은 종류가 연달아 오지 않는다. 단계에 맞는 후보 중에서 시드로 고른다.

| 단계 | 사건 | 모습 |
|---|---|---|
| 5+ | 혜성 통과 | 꼬리가 별 반대쪽으로 늘어지고, 별에 가까울수록 밝아진다. 상단 사건 띠를 지난다 |
| 5+ | 항성 홍염 | 집의 별 가장자리에 고리 모양 불꽃이 솟았다가 가라앉는다 |
| 5+ | 먼 초신성 | 원경의 별 하나가 부풀었다가 색 고리를 남긴다(시뮬레이션 별이 아닌 원경 전용) |
| 6+ | 유성 무리 | 소행성대 쪽에 작은 빛줄기 여러 개 |
| 6+ | 펄서 등대 | 초신성 잔해 중심에서 가는 빛살이 느리게 돈다. 점멸이 아니다 |
| 6+ | 별 탄생 연쇄 | 먼 성운에서 아기별 3~5개가 차례로 켜진다 |
| 7+ | 쌍성의 춤 | 두 별이 서로 돌며 그 사이에 가스 다리가 생긴다 |
| 8+ | 오로라 | 생명의 행성 극지방에 초록·장미빛 커튼 |
| 8+ | 달 그림자 | 달의 그림자 점이 행성 낮면을 지나간다 |
| 8+ | 밤면 유성우 | 생명의 행성 밤면에 작은 빛줄기 |
| 9+ | 은하 핵 맥동 | 은하 중심과 제트가 잠시 밝아진다 |
| 9+ | 위성 은하 통과 | 작은 은하가 원경을 가로지른다 |
| 10 | 궤도의 빛 | 생명의 행성 궤도에서 작은 빛이 떠올라 원경으로 사라진다 |

**③ 드문 사건** — 타임라인의 30분 블록에 묶인다(RARE).
- 대혜성(5+): 3분 동안 지나가며, 꼬리가 화면 폭의 3분의 1에 이른다.
- 킬로노바(6+): 원경의 두 작은 별이 나선을 그리며 돌다 합쳐지고, 금빛 먼지 구름이 남는다.
- 떠돌이 행성(4+): 어두운 행성이 별빛을 가리며 원경을 천천히 지나간다.
- 행성 정렬(8+): 집의 행성들이 한 줄로 늘어선다. 공전 주기에서 결정된다.
- 별 탄생 폭발(7+): 먼 성운 하나가 한꺼번에 밝아진다.

**④ 앰비언트** — 앰비언트 시계 t를 쓰고, Director의 ambient·fx 채널로 낸다.
- 별 반짝임, 변광성, 유성(50~120초 간격), 성운 호흡, 거미줄을 따라 흐르는 가스, 멀리 지나가는 소행성

**우선순위**: 이정표 > 드문 사건 > 세션 사건 > 앰비언트
- headline 채널은 동시에 하나만 쓴다.
- 카메라가 움직이는 동안과 이정표 연출 중에는 fx·ambient를 새로 시작하지 않는다.

## 13. 세션 별자리 (집중의 기록)

- 세션 구간 [시작 W, 끝 W] 동안 켜진 배경 별 중에서, 타이머 영역 밖에 있는 밝은 별 4~9개를 골라 잇는다(최소 신장 트리, 고리 없음).
- 세션이 끝나면 별먼지 금색의 가는 선이 4~6초에 걸쳐 차례로 그려진다. 그 뒤에는 투명도 0.12로 남는다.
- 화면에 선을 남기는 별자리는 최근 3~5개뿐이다. 나머지는 "자세히"의 **별자리 기록**에 이름·날짜·집중 시간과 함께 남는다.
- 이름은 시드와 세션으로 정한다. 형식은 "[꾸밈말] [사물]자리"이고 예는 잠든 고래자리, 작은 등불자리, 새벽 우체통자리, 접힌 편지자리다. 한국어 단어 목록을 각각 40개 이상 둔다.
- 세션이 2분 미만이거나 별이 3개 미만이면 별자리가 생기지 않는다.
- 일찍 끝낸 세션은 그때까지 켜진 별로 별자리를 만든다. 스톱워치도 같다.
- 별자리는 세션 구간 기록에서 나오는 결과다. 성장(W)에는 영향을 주지 않는다.
- 그리는 연출은 실시간으로 완료된 카운트다운과 사용자가 끝낸 세션에서만 한다. 늦게 알아챈 완료는 연출 없이 기록만 한다.

## 14. 살아 있는 움직임

이 테마의 최우선 품질 기준은 **처음부터 끝까지 살아서 숨 쉬는 우주**다.

- 첫 화면(빛 한 점)부터 잔잔한 움직임이 보여야 한다.
- 별, 성운 결, 가스 흐름, 행성, 은하, 먼지 띠를 서로 독립적으로 움직인다. 요소마다 주기, 진폭, 시작 위상이 다르다.
- 반복 움직임은 노이즈 기반으로 만들어, 처음으로 돌아갈 때 튀거나 끊기지 않게 한다. 키프레임 루프를 쓰지 않는다.
- 깊이는 움직임의 차이로 만든다. 근경(궤도, 행성)이 가장 크게, 중경(성운, 성단)은 중간, 원경(거미줄, 은하)은 가장 작게 움직인다.
- 성장은 대상의 형태대로 표현한다. 별은 매듭이 수축한 뒤 켜지고, 행성은 원반의 띠가 뭉쳐서 생기고, 성운은 껍질이 흩어지며 번진다. 크기만 키우는 성장은 쓰지 않는다.
- 위치·크기·밝기의 변화는 시작과 끝을 부드럽게 잇는다(ease, 2단 저역통과).
- 등장 연출은 보통 8~12초, 주변 사건은 4~8초에 걸친다.
- 타이머 주변은 차분하게 두고, 생동감은 가장자리와 하단에서 만든다.

## 15. 집중 보호·밝기·가독성·동작 줄이기

**밝기 안전**(빅뱅, 점화, 초신성, 킬로노바)
- 빅뱅의 정점에서도 화면 평균 상대 휘도는 0.35 이하로 둔다. 1초 사이 평균 휘도 변화는 8% 이하다.
- 상대 휘도 0.8을 넘는 영역은 화면의 2% 이하로 둔다.
- 점화, 초신성, 킬로노바는 밝아지는 데 3초 이상, 어두워지는 데 8초 이상 걸린다. 이때 화면 평균 변화는 5% 이하다.
- 깜빡임은 1초에 1회 이하다(WCAG 2.3.1보다 훨씬 낮게). 펄서는 점멸이 아니라 회전하는 빛살로 그린다.
- 캡처한 프레임에서 프레임 사이 평균 밝기 변화를 계산해 검수 기록에 남긴다.

**가독성**
- 타이머 숫자 뒤의 대비는 늘 4.5:1 이상이어야 한다. A 0:05, 0:30, 1:00, 2:00, 4:30, 10:00, 24:20, 3시간, 8시간에서 측정한다.
- 뜨거운 안개 시기에는 타이머 뒤를 한 톤 어둡게 하고 베일을 짙게 한다.

**타이머 영역 보호**
- 타이머 사각형 안의 입자 밀도는 ×0.35로 줄인다.
- 사건과 천체가 움직이는 경로는 타이머 영역을 피한다.
- 팝업은 없고, 알림은 상태 문구 한 줄로만 한다.

**동작 줄이기**(`prefers-reduced-motion` 또는 "애니메이션 끔")

| 항목 | 줄인 모습 |
|---|---|
| 빅뱅, 뜨거운 안개 | 번짐 대신 1fps로 상태만 바뀐다. 안개 결은 멈춘다 |
| 초신성 | 껍질의 크기만 상태로 보여준다 |
| 가스 흐름, 입자 | 없다. 대신 정지된 흐름 자국을 둔다 |
| 공전, 자전 | 위치는 W로 1fps 갱신한다. 앰비언트 움직임은 없다 |
| 카메라 | 고정 |
| 별자리 | 선이 바로 나타난다 |
| 세션 사건, 유성 | 그리지 않고 상태 문구만 남긴다 |

## 16. 카메라

- 기본은 고정 시점이다. 현재 형성 지점 쪽으로만 아주 조금(화면 폭의 8% 이내, 줌 +15% 이내) 기울어지고, 2단 저역통과로 12초 이상에 걸쳐 따라간다.
- **공개**: 성단이 완성되면 20초 동안 물러나 전체를 보여준다. 구역이 완성되면 은하까지 보이는 한 단계 넓은 구도를 30초 동안 보여준 뒤 돌아온다.
- **생명의 행성 방문**: 이정표(달, 바다, 생명, 첫 불빛)를 실행 중에 지날 때만 한다. 25초에 걸쳐 다가가 행성이 화면 짧은 변의 22%가 되게 하고, 60~90초 머문 뒤 25초에 걸쳐 돌아온다.
- 사건을 쫓지 않는다. 시간 점프 뒤에는 보간 없이 현재 구도로 맞춘다. 동작 줄이기에서는 움직이지 않는다.

## 17. 문구

- 말투는 기존 테마와 같은 "~해요"체로, 짧은 한 문장씩 쓴다. 상태 문구 예는 5절에 있다.
- 과학 내용은 실제 순서(빅뱅 → 재결합 → 첫 별 → 초신성 → 2세대 별과 행성)를 따르되 시간은 압축한다. 문구에서 수치를 단정하지 않는다.
- 완료 문구: **"집중한 시간만큼 별이 태어났어요."** 그 아래 한 줄: "오늘의 별자리: 잠든 고래자리"
- 완료 요약: "+25분 · 새 별 50개 · 새 행성 3개 · 단계 4 → 5"
- 소개 문구, FAQ, OG: "빛 한 점에서 시작해, 25분이면 첫 행성이 생겨요." 공유 이미지는 A=0과 A=24분 20초를 나란히 놓고 "25분 집중하면 빅뱅에서 첫 행성까지"라고 쓴다.

## 18. 소리 (선택, 기본 꺼짐)

- 환경음 "우주의 숨": 낮은 패드에 아주 느린 필터 움직임을 더한다.
- 빅뱅: 4초에 걸쳐 부드럽게 올라오는 소리. 굉음은 쓰지 않는다.
- 완료음: 별자리 선이 그려질 때 맑은 종소리 세 음.

## 19. 데이터·결정성·저장

- `ThemeId`에 `'cosmos'`를 더하고, 세계 저장에 W₀를 더한다. W₀가 없으면 이 테마를 처음 고를 때 한 번 기록한다.
- 데이터 버전을 바꿔야 하면 이관은 멱등으로 한다. 이관 전후 숲·우주의 결과가 같아야 한다.
- 시뮬레이션은 `src/sim/cosmos.ts`에 두고, 체크포인트 규칙은 기존과 같다(테마별 키, 버전이 다르면 버림).
- 테스트에 추가할 것
  - 분할 독립: 5분×5 = 25분×1, 무작위 400조각
  - 단계 비감소, 자원 회계 불변식
  - 세션 사건이 성장에 영향을 주지 않음
  - 별자리 결정성(같은 세션 기록이면 같은 별자리)
  - W₀는 한 번만 기록되고, "새 우주 시작"이 숲·우주에 영향을 주지 않음
  - 이정표의 순서와 시각

## 20. 성능

- 빅뱅 안개는 미리 칠한 텍스처 2~3장의 UV 흐름과 색 램프로 만든다. 매 프레임 Canvas 2D로 그리지 않는다. 입자는 Director 예산 안에서 쓴다.
- 성운은 수채 텍스처 몇 장을 겹치고, 밝기 호흡은 알파로 한다.
- 목표: 기존과 같은 방식(A 0 / 4시간 / 2,000시간의 프레임 CPU, 카드 수 상한)으로 측정하고, 숲·우주와 같은 수준 이하로 맞춘다.
- CPU 4배 감속 측정은 실기기를 대신하는 대용 측정임을 명시한다.

## 21. DEV 도구

- A와 단계, 다음 이정표, 자원, 우주 날씨를 표시한다.
- 시간 이동(+10초 ~ +100시간), "다음 이정표 −20초", "세션 사건 부르기(10초 뒤)", "새 우주 시작"

## 검수 (모든 Phase 공통)

- 관찰하지 않은 화면과 실행하지 않은 테스트를 확인했다고 쓰지 않는다. 결과와 남은 점은 `docs/COSMOS.md`의 검수 기록에 관찰한 그대로 적는다.
- 화면 검수는 headless Playwright의 `?store=cosmos-*` 이름공간에서만 한다. 사용자의 기본 저장과 열린 탭은 건드리지 않는다.
- 데스크톱 1440×820과 모바일 390×844에서 고정 시드로 스크린숏을 찍는다.

**반드시 확인할 것**
1. A=0에서 DEV 시간 이동 없이 5분 카운트다운을 돌렸을 때 빅뱅, 뜨거운 안개, 투명해짐, 거미줄, 첫 별이 보이는지(실제 속도 녹화).
2. 첫 25분 세션의 0·25·50·75·100% 화면이 서로 분명히 다른지.
3. 첫 행성계 이후 5분 세션마다 세션 사건이 1개 이상, 25분 세션에서 3~5개 오는지(시뮬레이션 측정, 그리고 최소 한 번은 실제 속도 녹화).
4. 30초 이상 지켜볼 때 성운, 안개, 별, 흐름이 반복 경계에서 튀지 않는지.
5. 일시정지하면 성장과 앰비언트가 모두 멈추고, 재개하면 이어지는지. 다른 탭에서 돌아왔을 때 지나간 이정표를 다시 재생하지 않는지.
6. 빅뱅, 첫 초신성, 킬로노바의 밝기 측정값과, 15절 시점들의 대비 측정값.
7. 동작 줄이기 화면, 두 탭 1분 카운트다운(한 번만 적립), 운영 빌드 콘솔 0건.
8. 숲·우주의 기존 테스트가 모두 통과하고 저장 데이터가 바뀌지 않는지.
