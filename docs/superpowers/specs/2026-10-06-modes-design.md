# 성장 속도(가속)와 시계 모드 — 설계

2026-10-06. 사용자 확인: 성장 배율, ×1·×2·×5·×10, 전부 세계 시간 기준, 시계는 성장 없음, 세 번째 모드 버튼.

## 1. 성장 속도

- 설정 `growthRate: 1 | 2 | 5 | 10`이고 기본은 1입니다. 설정 메뉴의 `성장 속도` 줄에서 고릅니다.
- 세션을 시작할 때 그 값이 `Session.rate`로 고정됩니다. 세션 중에 바꾸면 다음 세션부터 적용됩니다.
- 세계 시간 W는 `bankedMs + E × rate`입니다(E는 실제 경과 시간). 세션이 끝나면 `bankedMs += E × rate`가 됩니다.
  - 카운트다운의 T는 실제 시간이므로, 25분 타이머는 25분 뒤에 끝납니다.
- 실제 집중 시간은 `World.focusMs`입니다. 없으면 `bankedMs`로 읽습니다(그동안은 모두 ×1이었으므로).
  - 이 값은 배율을 처음 쓸 때부터 기록하므로, ×1만 쓴 세계의 저장값은 지금과 같습니다.
- 세션 구간(pace)의 `len`은 세계 시간 길이 T × rate입니다. 사건(세션 사건, 습격)은 세계 시간 기준이라 배율만큼 잦고 짧아집니다(사용자 선택).
- 은하의 우주 나이 A = W − origin도 같이 빨라집니다.
- 저장: `Session.rate`와 `World.focusMs`는 선택 필드입니다. 잘못된 값은 버리므로(1과 bankedMs로 읽음) 데이터 버전은 그대로입니다.

## 2. 표시

- **설정 메뉴**: `성장 속도 ×1 ×2 ×5 ×10`. 세션 중에 바꾸면 "다음 세션부터 적용돼요"라고 알립니다.
- **배지**: 배율이 1이 아니면 타이머 아래 글귀 옆에 `×5` 배지를 붙입니다(대기 중에는 설정값, 세션 중에는 세션 값).
- **아래 상태 줄**: 실제 집중 시간과 세계 시간이 다르면 `집중 X · 풍경 Y · …`로, 같으면 지금처럼 `누적 Y · …`로 보입니다.
- **완료 요약**: 배율이 1이 아니면 "25분 집중했고, 풍경은 ×5로 2시간 5분만큼 자랐어요."라는 줄이 붙습니다. 요약이 비교하는 "세션 뒤 세계"도 E × rate를 씁니다.
- **자세히**: 세 테마 모두 `집중 시간` 줄(실제 X · 풍경 Y)이 추가됩니다.

## 3. 시계 모드

- 설정의 모드는 `countdown | stopwatch | clock`입니다. 세션의 모드는 그대로 `countdown | stopwatch`이고, 시계 모드에서는 세션을 시작할 수 없습니다.
- 위쪽 전환은 `카운트다운 · 스톱워치 · 시계`입니다. 진행 중인 세션이 있으면 지금처럼 바꿀 수 없습니다.
- 화면에는 큰 현재 시각(`오후 3:42`, 초는 작게)과 날짜(`10월 6일 화요일`)가 나오고, 1초마다 갱신됩니다.
  - 상태 글귀, 시작 버튼, 스페이스 키로 시작하기는 없습니다.
- 성장과 기록은 없고, 풍경은 대기 상태의 잔잔한 움직임만 보입니다.
- 5초 동안 조작이 없으면 위쪽 막대, 아래 정보, 시계 도구가 흐려지고 커서가 숨습니다. 포인터, 터치, 키, 휠이 들어오면 다시 보입니다.
- 화면 잔상을 막으려고 시각 글자의 위치가 몇 분 주기로 몇 픽셀씩 천천히 옮겨 다닙니다.
- 시계 아래에 `전체 화면` 버튼이 있습니다(Fullscreen API를 쓸 수 있을 때만).
- 끝난 세션의 요약이 남아 있어도 시계 모드에서는 시계를 보여 줍니다. 다른 모드로 돌아가면 요약이 다시 나옵니다.

## 4. 작업과 검증

- 워크트리 브랜치 `worktree-feat-modes`에서 작업하고, 사용자가 요청하면 main에 합칩니다.
- 단위 테스트:
  - 배율: W, 쌓이는 양, focusMs, pace 길이, 세션 중 설정 변경, 저장·불러오기, 잘못된 값, 예전 저장 데이터
  - 시계: 시작이 거부되는지, 세션 중 모드 전환이 막히는지
- 화면 확인(headless, `?store=`):
  - ×5·×10 실제 속도 세션의 프레임 시간(세 테마)
  - 배지, 상태 줄, 요약, 자세히
  - 시계 모드: 데스크톱과 휴대폰 크기, 흐려짐과 복귀, 전환 막대 폭
