# 모아 · 설계 문서 (v1)

> 핵심 문장: **집중한 시간이 모여 나만의 숲과 기지가 됩니다.**
> 이 문서는 구현 전에 정한 구도·색·에셋 분리·성장 타임라인·카메라 문법을 기록한다.
> 숫자(15분, 4개, 4개)는 `src/core/rules.ts`의 규칙 버전 1 기본값이며 사용성 검증 후 조정한다.
>
> **데이터 버전 2 이후**: 3절(15분 성장 타임라인), 4절(성장 단계 카메라), 7절(성장 단계 사건)은 작업·자원 시뮬레이션으로 대체되었다.
> 나무·시설의 그림 단계(u)는 그대로 쓰지만, u는 이제 숲지기의 돌봄으로 자라는 성장량과 로버의 조립 단계에서 나온다.
> 현재 규칙·카메라·효과는 `docs/IMPROVEMENT.md`, 튜닝 값은 `src/sim/config.ts`를 따른다.

## 1. 공통 화면 문법

| 영역 | 데스크톱(가로) | 모바일(세로) |
|---|---|---|
| 타이머·버튼 | 화면 중앙 (x 0.33–0.67, y 0.26–0.62) | 상단 중앙 (y 0.12–0.48) |
| 근접 대상(새싹·작업 구역) | 하단 중앙 (x 0.32–0.68, y 0.68–0.95) | 하단 (y 0.64–0.95) |
| 군락·전초기지 | 좌/우 측면 (x 0.05–0.37 / 0.63–0.95) | 하단 전체 (y 0.56–0.96) |
| 넓은 구역 | 하단 45% 전체 | 하단 42% 전체 |

* 세계 카메라는 "대상의 월드 bbox → 화면의 대상 영역" 맞춤으로 계산한다. 타이머 여백은 화면 영역으로 정의되므로 카메라가 바뀌어도 중앙 가독성이 유지된다.
* 최소 관찰 크기: 성숙한 나무/시설의 화면 높이 ≥ max(84px, 화면 짧은 변의 12%). 이보다 작아지는 줌아웃은 하지 않는다.
* HTML UI는 캔버스 위 고정 레이어. 카메라 변화와 무관하게 크기·위치가 일정하다.

## 2. 세계 구조 (두 테마 공유)

```
단위(unit)   = 나무 1그루 / 시설 1개          C = 누적 15분
군락(cluster) = 단위 4개 / 전초기지          = 1시간
구역(zone)    = 군락 4개 / 정착 구역          = 4시간
이후 구역이 오른쪽으로 이어진다 (zone k의 원점 x = k·ZW)
```

* 구역 안의 군락 배치: 왼쪽 앞(c0) → 오른쪽 앞(c1) → 왼쪽 뒤(c2) → 오른쪽 뒤(c3). 중앙은 길과 샘(숲) / 착륙장(우주)을 위한 공터로 비워 둔다.
* 길(숲)과 통로·궤도(우주)는 구역 경계를 넘어 하나의 곡선 `d(x) = 0.3 + 0.25·cos(2πx/ZW)`로 이어진다. 그래서 새 구역은 이전 구역과 같은 장소로 읽힌다.
* 상세 렌더링: 현재 구역 + 바로 이전 구역(성숙 상태). 그보다 오래된 구역은 원경 능선의 "기억 패치"(LOD 실루엣/불빛)로 남고, 패치 수는 상한(12)에 도달하면 밀도 띠로 합쳐진다.
* 모든 변주는 `hash(worldSeed, zone, unit, salt)`로 선택한다. 새로고침해도 다시 추첨되지 않는다.

## 3. 성장 타임라인 (단위 진행도 u ∈ [0,1), 1u = 15분 = 900초)

### 숲 · 한 그루
| u | 실제 시간 | 변화 |
|---|---|---|
| 0.000–0.012 | 0–11초 | 흙이 미세하게 부풀고 씨앗이 보인다 |
| 0.012–0.036 | 11–32초 | 씨앗 껍질이 갈라지고 갈고리 모양 새싹이 올라온다 |
| 0.036–0.062 | 32–56초 | 떡잎 두 장이 접점에서 펼쳐진다 (각 ~10초) |
| 0.06–0.22 | ~1–3분 | 줄기가 뻗고 본잎이 마디마다 차례로 펼쳐진다 |
| 0.22–0.55 | 3–8분 | 줄기가 목질화·굵어지고 가지가 갈라진다 (가지마다 ~50초) |
| 0.40–0.85 | 6–13분 | 잎 묶음이 가지 끝에서 하나씩 펼쳐져 수관이 풍성해진다 (각 ~10초) |
| 0.86–0.93 | 13–14분 | 몇 장의 잎이 떨어져 뿌리 주변에 남는다 (각 ~6초) |
| 0.965–0.978 | ~14.5분 | 바람에 씨앗이 다음 빈자리로 날아간다 (~12초) |
| 0.978–1.0 | 마지막 20초 | 씨앗이 다음 자리의 흙 위에 놓인다 → 다음 단위 u=0과 같은 그림 |

### 우주 · 시설 하나
| u | 변화 |
|---|---|
| 0–이동시간 | 로버가 이전 작업 지점에서 도착 (바퀴 회전 = 이동거리/반지름) |
| ~0.02–0.07 | 작업 구역 측량선이 점선으로 그려지고 모서리 말뚝이 꽂힌다 |
| 0.07–0.20 | 기초 패드 조각이 접합부부터 하나씩 내려앉는다 |
| 0.20–0.45 | 골조(리브)가 접합 지점에서 위로 자란다 |
| 0.45–0.70 | 외벽 패널이 리브 사이에 순서대로 붙는다 |
| 0.70–0.85 | 용도 장비: 태양광 날개(힌지 회전)·안테나·온실 유리·관측 돔 |
| 0.85–0.92 | 창문과 표시등에 따뜻한 불이 하나씩 들어온다 |
| 0.92–0.99 | 통로/전력선이 다음 작업 지점 방향으로 이어진다 |

* 모든 요소의 상태는 세계 누적 시간 W의 **순수 함수**다. 새로고침·복귀·테마 전환 후에도 같은 W면 같은 그림이며 중복 생성이 원천적으로 없다.
* 국소 펼침·등장 창은 실제 실행 시간 기준 8–12초, 주변 사건은 4–8초.

## 4. 카메라 문법

| W 상태 | 프레이밍 | 전환 |
|---|---|---|
| 구역 첫 단위 u<0.22 | 근접 (씨앗·흙·이끼·돌) | — |
| 구역 첫 단위 u<0.45 / 그 이후 | 묘목 → 한 그루 | 12초 |
| 군락 내 다음 단위 | 군락 bbox (측면) | 12초 |
| 군락 마지막 단위 u∈[0.86,0.965) | 지금까지의 구역 전체 (공개) | ~20초 |
| 구역 마지막 단위 u∈[0.86,0.965) | 구역 전체 + 샘/착륙장 발견 | ~20초 |
| u ≥ 0.965 (씨앗 비행/로버 출발) | 다음 단위의 프레이밍 | 12–25초 |

* 카메라 위치·로그 줌은 2단 저역통과 필터로 따라간다 (시작·끝 속도 0, 목표 변경에도 C¹ 연속).
* 시간 점프(새로고침, 백그라운드 복귀, 개발 도구)는 보간 없이 바로 현재 구도로 맞춘다 → 지나간 카메라 연출을 몰아서 재생하지 않는다.
* 시점 고정: 목표 갱신 중지. 모션 감소: 현재 구역 전체 정적 보기, 상시 움직임 중지.

## 6. 에셋 분리 계획

외부 이미지 생성 도구가 없으므로 모든 아트워크는 **런타임 절차적 과슈 페인팅**(Canvas2D → PixiJS 텍스처)으로 제작한다. 붓 질감 함수(`src/scene/paint`)를 두 테마가 공유해 스타일을 통일한다.

| 에셋 | 기준점(anchor) | 회전 중심 | 레이어 | 등장 구간 | 연결 지점 | 접지 |
|---|---|---|---|---|---|---|
| 줄기/가지(Graphics) | 뿌리 | 뿌리(skew) | mid, depth 정렬 | 0.012–0.55 | 가지 끝 → 잎 묶음 | 타원 그림자 |
| 잎 묶음(Sprite) | 가지 끝 | 가지 접점 | 줄기 위 | 0.40–0.85 | — | — |
| 떡잎/본잎 | 마디 | 마디 | 줄기 위 | 0.036–0.22 | — | — |
| 낙엽 | 수관 | 잎자루 | 줄기 앞 | 0.86–0.93 | 뿌리 주변 정착 | 정적 낙엽층 |
| 풀·꽃·이끼·돌 | 밑동 | 밑동(skew) | 전경/중경 | 구역·군락 단계 | — | 바닥 |
| 시설 패드·리브·패널 | 패드 중심 | 접합부 | mid | 0.07–0.70 | 통로 포트 | 그림자 |
| 태양광 날개 | 힌지 | 힌지 | 시설 위 | 0.70–0.85 | — | — |
| 창문빛 | 창 | — | add | 0.85–0.92 | — | 바닥 빛웅덩이 |
| 로버 | 차체 하단 | 바퀴 축 | mid | 이동 구간 | — | 그림자 |

* 모바일 배치: 구역 폭과 군락 오프셋을 세로 화면용 테이블로 교체한다(`layout.ts`).
* 텍스처 가장자리에 흔들림·카메라 여유 패딩(반지름의 15%)을 둔다.
* 원경·안개·종이 질감은 한 번 그려 고정한다(프레임마다 노이즈를 새로 만들지 않음).

## 7. 사건 문법

* 사건은 각 단위의 성장 단계(새싹 직후, 잎 펼침 중반, 성숙 후)에 시드로 배치된 W 구간이다.
* 같은 종류 연속 금지, 최소 간격 120초(W), 군락·구역 공개 구간에는 사건 없음, 동시에 하나.
* 사건은 페이지가 그 시작 시점을 **실행 중에 직접 지나갈 때만** 재생한다(새로고침·복귀·점프 후에는 생략).
